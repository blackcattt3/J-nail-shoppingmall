## 💅 J.nail shoppingmall
### 네일 아트 상품을 탐색·구매할 수 있는 React 기반 이커머스 웹 서비스입니다.

#### demo : https://j-nail-shoppingmall.vercel.app/

### ✨ 주요 기능
- 회원가입 / 로그인 (로그인 상태 유지)
- 상품 목록 조회 및 상세 페이지
- 장바구니 추가 / 삭제 / 수량 변경
- 주문 페이지 및 주문 완료 처리
- 로딩 / 에러 / 빈 상태 UI 분기 처리

### 🛠 Tech Stack
- React
- React Router
- Context API (전역 상태 관리)
- JavaScript (ES6+)
- CSS
- LocalStorage

### 🧠 구현 포인트
- 로그인 상태를 Context + LocalStorage로 관리하여 새로고침 시에도 상태 유지
- 장바구니 데이터 흐름을 기준으로 컴포넌트 구조 설계
- 로딩 / 에러 / 데이터 없음 상태를 분리해 사용자 혼란 최소화

### 🐞 Troubleshooting

#### 1. 상세 페이지 로딩 중 빈 화면 노출 문제
- **문제**
  - 상품 상세 페이지 진입 시 데이터 로딩 중 화면이 비어 보이며 사용자가 오류로 인식하는 문제가 발생
- **해결**
  - 로딩 상태 / 데이터 없음 / 에러 상태를 명확히 분리하여 각각에 대응하는 UI를 구성
  - 데이터 상태에 따른 화면 분기 처리를 통해 사용자 혼란을 최소화하고 UI 흐름을 안정화

---

#### 2. 상품 상세 단건 조회 시 404 오류 발생
- **문제**
  - JSON Server를 통한 상품 단건 조회 요청 시 간헐적으로 404 오류가 발생
- **원인**
  - API 라우트 환경 설정 및 json-server 버전 이슈로 범위를 한정
- **해결**
  - 안정화된 json-server 버전을 적용하여 단건 조회 API 정상 동작 확인 및 문제 해결

---

#### 3. 새로고침 시 Private Route 접근 문제
- **문제**
  - 로그인 상태임에도 새로고침 시 Private Route에서 로그인 페이지로 이동되는 현상 발생
- **해결**
  - 초기 렌더 단계에서 localStorage에 저장된 인증 정보를 복원하도록 구조 개선
  - 인증 상태가 복원된 이후 라우트 판단이 이루어지도록 하여 의도치 않은 페이지 이동 문제 해결
